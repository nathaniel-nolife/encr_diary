## A simple encrypted library with the basic functions:

# Usage:
```bash
$ cargo run <COMMAND>
```
Commands:
```bash
  add :only for this if you wish to mention title use -t or --title flag | add an entry    
  list | list the titles and ids
  view <id> | view the entry
  edit <id>  | edit the entry
  delete <id>  | delete the entry
  change-password | change the password
```
